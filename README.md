## The blog

**Title:** Reinforcing Recursive Language Models
**Authors:** NovaSky-AI / SkyRL contributors (acknowledging Sumanth Hegde, Charlie Ruan, Alex Zhang)
**Venue:** alphaXiv blog post, May 2026

**Headline claim.** RL fine-tune small (4B) models to behave as native recursive language models (RLMs) by training parent and child RLMs under a *single shared policy*. With RL, small models learn task-specific RLM behavior that cannot be elicited through prompting or even SFT alone. Children inherit the parent's GRPO advantage (with $1/k_g$ averaging across children), so the entire recursive call tree is optimized as one trajectory.

**Key result.** On an evidence-selection task over multi-paper scientific corpora, an RL-fine-tuned **Qwen3.5-4B matches Claude Sonnet 4.6** (avg rubric ≈ 0.6) using the same RLM scaffold + Python REPL — at **8.5× faster wall-clock** (7s vs 60s per query) and a fraction of the size and cost.

## Run the sandbox

```bash
cd sandbox && pip install -r requirements.txt
python3 toy_recursive_bandit.py   # ~30s on CPU; reward 0.30 → 0.97
python3 tiny_gpt_rlm.py           # ~5min on CPU; reward 0.27 → 0.52, KL=12.7
```

Both demonstrate the central technical claim: a single shared policy + child-inherits-parent-advantage GRPO is sufficient to train recursive agentic behavior.

## Chain-repo cross-links

This study sits on top of [`pleyva2004/first-principles-to-llms`](https://github.com/pleyva2004/first-principles-to-llms), the chain that walks from set theory to GRPO. Specifically:

- **Chain Ch 25** — causal LM as MDP (every node in the RLM tree is a Ch 25 MDP)
- **Chain Ch 27** — tiny GPT pre-training pipeline (the backbone here is the same idea, scaled to Qwen3.5-4B)
- **Chain Ch 28** — SFT, RLHF (PPO/GRPO), DPO (cold-start SFT and PPO-clipped per-node loss are direct lifts)
- **Chain Ch 29** — MDP foundations + Bellman (lifted to a tree)
- **Chain Ch 30** — max-entropy RL (justifies KL regularization to a reference policy)
- **Chain Ch 31** — policy gradient + GRPO derivation + RLHF/DPO bridge (the recursive-subtree loss is the chain Ch 31 GRPO objective lifted from sequence to tree)
